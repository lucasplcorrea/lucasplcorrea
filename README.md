## 💡 Minha filosofia

Não acredito que toda solução precise começar como um grande projeto.

Muitas vezes ela começa com:

```text
um problema
    ↓
um script
    ↓
uma automação
    ↓
uma aplicação
    ↓
"como vivíamos sem isso antes?"
```

Gosto especialmente de projetos que conectam **desenvolvimento + infraestrutura + automação**.
